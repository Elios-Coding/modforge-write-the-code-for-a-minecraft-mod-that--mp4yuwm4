# Secret Menu XRAY Toggle

Client-side Secret Menu opened with '*' (numpad multiply) that toggles an XRAY render mode making non-ore blocks invisible while keeping ores visible.

Generated by **ModForge AI**.

- Minecraft: `1.21.11`
- Loader: Fabric `0.18.4`
- Fabric API: `0.141.4+1.21.11`

## Build

```bash
./gradlew build
```

The compiled `.jar` will be placed in `build/libs/`. GitHub Actions builds it automatically on push and publishes it to Releases.
